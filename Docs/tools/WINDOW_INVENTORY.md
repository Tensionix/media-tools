# Опись прежнего окна (NiceGUI, 2.6.1)

Что окно на NiceGUI делает само, помимо передачи формы движку. Снято 15.10.2026 с кода эталона
`E:\TOOLS\Audion Media Tools NiceGUI` (`system_core\ui_nicegui\app.py` 5970 строк, `window.py`, `workbench.py`) и с его консольных
меню. Каждая строка при переносе получает отметку в последнем столбце: **перенесено**, **заменено** (чем) или **убрано, потому что**.

Параметры, которые окно отдаёт движку, записаны отдельно и числом: `tests\former_window_parameters.json` (сценарий
`tests\capture_former_window_parameters.py`). Тексты окна - подписи и подсказки - снимаются в карту прежнего окна (раздел 10.3 спека).

Куда: **модель** - `system_core\core\operation_model.py` (правила формы, одна копия для окна и консоли); **движок** - служба или
`media_cli.cmd`; **окно** - Avalonia; **данные** - манифест, раскладка, `Source\config\i18n.json`.
