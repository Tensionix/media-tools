# Скачивание

[English](YOUTUBE_DOWNLOAD_EN.md)

## Назначение

Раздел СКАЧАТЬ использует yt-dlp из папки программы (`Tools\yt-dlp`; для YouTube рядом нужен Deno, он ставится вместе с
yt-dlp). Режимы раздела — форматные профили: ЛУЧШЕЕ MP4, НАДЁЖНОЕ MP4, СВОЁ ВИДЕО, ДЛЯ ЗАГРУЗКИ, СВОЁ АУДИО, СУБТИТРЫ.
Скачанное ложится в `output\Download` (или в `Download` выбранного Назначения), ход скачивания — строками `[download]`
в журнале. Имя файла — `<автор>\<дата> - <название> [<id>].<ext>`, у плейлиста — `<номер> - <название> [<id>].<ext>`;
в конце журнал называет каждый записанный файл строкой `[OK]`, а итог консольной команды — списком `downloaded`.

## Источники

Поле `Источник` раздела:

- `Одна ссылка` — поле `URL`. Кнопка `ВСТАВИТЬ` справа берёт ссылку из буфера обмена; ⓘ показывает в журнале, какие
  форматы ссылка предлагает (разрешение, кодеки, размер), ничего не скачивая. Ссылка на видео внутри плейлиста берёт
  одно это видео.
- `input\urls.txt` — список ссылок, по одной на строку. Файл можно выбрать другой (`Файл ссылок`, с той же кнопкой
  `ВСТАВИТЬ` для пути).
- `Плейлист` — весь плейлист по ссылке; `Диапазон списка` берёт его часть, например `1-10` или `3,5,7`.

`Фрагмент` скачивает кусок по времени, а не всё видео.

## Форматные профили

| режим | что берёт |
|---|---|
| ЛУЧШЕЕ MP4 | лучшее видео и звук, сведённые в MP4/M4A; общий профиль без особых требований. Картинка может прийти в AV1 — его играет не каждая программа |
| НАДЁЖНОЕ MP4 | для капризных ссылок, которые обрываются: другой клиент, повторы, IPv4 |
| СВОЁ ВИДЕО | разрешение, кодек, звук и контейнер задаются полями ниже |
| ДЛЯ ЗАГРУЗКИ | H.264 со звуком AAC в MP4 — то, что примет любая площадка и программа |
| СВОЁ АУДИО | только звук в выбранном формате |
| СУБТИТРЫ | только субтитры, без медиа |

Пресеты над полями (`Профиль скачивания`) — готовые сочетания: Best MP4 video, 1080p AVC MP4, Safe Safari, AV1 если
доступен, Audio MP3, Batch из urls.txt.

## Видео и звук

Поля:

- `Разрешение`: лучшее, 2160p, 1440p, 1080p, 720p, 480p.
- `Видео кодек`: Auto, AVC/H.264, AV1, VP9.
- `Формат аудио`: родной, M4A, Opus, MP3.
- `Контейнер`: MP4, MKV, WEBM.

Рекомендации:

- Для максимальной совместимости: ДЛЯ ЗАГРУЗКИ или пресет 1080p AVC MP4.
- Для обычной загрузки без строгих требований: ЛУЧШЕЕ MP4.
- Только звук: СВОЁ АУДИО (например, `Формат аудио` = M4A) или пресет Audio MP3.
- Субтитры без медиа: СУБТИТРЫ.

## Тюнинг скачивания

Флажки:

- `Повторы` — полезно при нестабильной сети.
- `IPv4` — иногда помогает, если маршрут IPv6 ломает загрузку.
- `Метаданные + обложка` — встраивает метаданные и обложку, где возможно.
- `Без плейлиста` — для ссылок из `input\urls.txt`: не разворачивать плейлист случайно. Одна ссылка плейлист не
  разворачивает никогда.

`Потоки` — сколько фрагментов качается сразу; `Клиент` — каким клиентом представляться YouTube (Default, Safari,
Android).

## Субтитры

Поля:

- `Ручные`;
- `Авто`;
- `Встроить`;
- `Языки субтитров`.

Языки лучше указывать явно, например:

```text
ru,en
```

или:

```text
en.*,ru.*
```

в зависимости от формата yt-dlp и источника.

## Cookies

Ссылкам, где yt-dlp должен видеть вход в учётную запись, нужны cookies. Поле `Cookies`:

- `Нет`;
- `Chrome`, `Edge`, `Firefox`, `Brave` — cookies браузера берутся в момент скачивания;
- `Файл` — файл cookies (`Файл cookies`, по умолчанию `config\cookies.txt`; кнопка `ВСТАВИТЬ` — путь из буфера).

Щит рядом с файлом запечатывает его DPAPI для этой учётной записи Windows в `config\cookies.dpapi`: скачивание с
`Файл` берёт эту копию, и открытый файл больше не нужен — его можно удалить.

По умолчанию стоит `Файл`: запечатанная копия, а без неё — файл поля, уходит с каждым скачиванием, если он есть.
Публичной ссылке cookies не нужны — для неё можно выбрать `Нет`.

Правила:

- не хранить cookies в публичном репозитории;
- не отправлять cookies вместе с отчётами;
- при ошибках сначала проверить путь и формат файла cookies.

## Архив скачиваний

`Вести архив скачиваний` включает архив yt-dlp (`config\download-archive.txt`). По умолчанию он выключен, чтобы
пользователь явно решал, нужно ли пропускать уже скачанные ссылки.

Включай архив, если пачка повторяется регулярно и важно не скачивать одно и то же дважды.

## Сухой прогон

`Только показать команду` и кнопка КОМАНДА показывают настоящий вызов yt-dlp до запуска.

Проверяй его, когда меняешь:

- клиент;
- cookies;
- субтитры;
- контейнер;
- источник ссылок;
- архив скачиваний.

## Типовые ошибки

### Скачался плейлист вместо одного видео

Это ссылки из `input\urls.txt`: включи `Без плейлиста`.

### Ссылка работает в браузере, но не в yt-dlp

Попробуй:

1. НАДЁЖНОЕ MP4 или пресет Safe Safari;
2. `IPv4`;
3. cookies браузера;
4. обновить yt-dlp: SETTINGS → КОМПОНЕНТЫ → ОБНОВИТЬ или СЕРВИС → «Установить yt-dlp».

### Не те субтитры

Проверь `Языки субтитров` и раздели ручные и автоматические. У некоторых источников есть только автоматические.

### MP4 не получился

Причины:

- источник даёт только VP9/AV1/WebM;
- выбрано несовместимое сочетание кодека и контейнера;
- yt-dlp не может свести потоки без перекодирования.

Для совместимости выбирай ДЛЯ ЗАГРУЗКИ.
