# Скачивание / YouTube

## Назначение

Раздел `Скачивание / YouTube` использует yt-dlp напрямую из portable-пакета. Он заменяет старый отдельный downloader и живёт в общем GUI-контуре: профили, поля, dry-run, лог и отчёт.

## Источники

Есть два режима:

- одна ссылка в поле `URL`;
- batch из `Download\urls.txt`.

Для batch режима удобно держать файл:

```text
Download\urls.txt
```

по одной ссылке на строку.

## Основные Профили

### Best MP4 video

Общий профиль для обычной загрузки. Старается получить лучший MP4/M4A merge.

Используй, когда нет специальных требований к codec, resolution или client.

### 1080p AVC MP4

Совместимый H.264/MP4 профиль. Хорош для устройств, сервисов и программ, которые плохо принимают AV1/VP9.

### Safe Safari

Профиль для капризных ссылок:

- Safari client;
- retries;
- IPv4.

Если обычный профиль ломается на YouTube, начни с этого.

### AV1 Если Доступен

Предпочитает AV1 video, сохраняя управляемый контейнер. Подходит для современных архивов и тестов качества, но не всегда лучший выбор для старых устройств.

### Audio MP3

Audio-only extraction в MP3.

### Batch из urls.txt

Читает ссылки из `Download\urls.txt`.

## Форматный Профиль

Поле `Форматный профиль` определяет общий тип yt-dlp selection:

- `Best MP4`;
- `Safe MP4`;
- `Custom video`;
- `Upload ready`;
- `Custom audio`;
- `Только субтитры`.

Если нужен полный контроль, выбирай custom и задавай codec/container/audio ниже.

## Видео И Аудио

Поля:

- `Разрешение`: best, 2160p, 1440p, 1080p, 720p, 480p.
- `Видео кодек`: auto, AVC/H.264, AV1, VP9.
- `Формат аудио`: source, M4A, Opus, MP3.
- `Контейнер`: MP4, MKV, WEBM.

Рекомендации:

- Для максимальной совместимости: 1080p AVC MP4.
- Для современной загрузки без строгих требований: Best MP4.
- Для audio-only: Custom audio или Audio MP3.
- Для субтитров без медиа: `Только субтитры`.

## Тюнинг Скачивания

Чекбоксы:

- `Повторы` - полезно при нестабильной сети.
- `IPv4` - иногда помогает, если IPv6 routing ломает загрузку.
- `Метаданные + обложка` - встраивает metadata/thumbnail, где возможно.
- `Без плейлиста` - не разворачивать плейлист случайно.

## Субтитры

Поля:

- `Ручные`;
- `Авто`;
- `Встроить`;
- `Языки субтитров`.

Языки лучше указывать явно, например:

```text
ru,en
```

или:

```text
en.*,ru.*
```

в зависимости от yt-dlp формата и источника.

## Cookies

Поле `Cookies` нужно для ссылок, где yt-dlp должен видеть авторизованную сессию.

Правила:

- не хранить cookies в публичном репозитории;
- не отправлять cookies вместе с отчётами;
- при ошибках сначала проверить путь и формат cookies-файла.

## Download Archive

`Вести архив скачиваний` включает yt-dlp archive. По умолчанию он выключен, чтобы пользователь явно решал, нужно ли пропускать уже скачанные ссылки.

Включай archive, если batch повторяется регулярно и важно не скачивать одно и то же дважды.

## Dry Run

`Только показать команду` и кнопка `Команда` помогают увидеть реальный yt-dlp вызов до запуска.

Проверяй dry-run, когда меняешь:

- client;
- cookies;
- subtitles;
- container;
- batch mode;
- download archive.

## Типовые Ошибки

### Скачался Плейлист Вместо Одного Видео

Включи `Без плейлиста`.

### Ссылка Работает В Браузере, Но Не В yt-dlp

Попробуй:

1. `Safe Safari`;
2. `IPv4`;
3. cookies;
4. обновить yt-dlp через installer/builder.

### Не Те Субтитры

Проверь `Языки субтитров` и раздели manual/auto subtitles. Некоторые источники имеют только auto captions.

### MP4 Не Получился

Причины:

- источник даёт VP9/AV1/WebM;
- выбран несовместимый codec/container;
- yt-dlp не может remux без дополнительного transcode.

Для совместимости выбирай `1080p AVC MP4`.
